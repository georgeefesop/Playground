# Assets

## Character Sprite

Place your character sprite sheet here as: `character-sprite.png`

### Sprite Sheet Format

The code expects a standard RPG Maker style sprite sheet:
- **Size**: 48x64 pixels (16x16 per frame, 3 columns x 4 rows)
- **Layout**:
  - Row 0: Down-facing walk animation (3 frames)
  - Row 1: Left-facing walk animation (3 frames)
  - Row 2: Right-facing walk animation (3 frames)
  - Row 3: Up-facing walk animation (3 frames)
